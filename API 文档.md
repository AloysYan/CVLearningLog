### API 文档 



我们规定用 USB CDC 通讯，STM32 开启请看[stm32 cdc 开启教程](https://blog.csdn.net/qq_36347513/article/details/127404464)

我尽量把所有我能想到的信息都写上了，后续如果有需要就减少沟通成本，当然很多接口目前都不需要实现，有的可能一直不需要，我这里写上只是防止可能需要



| **项目**       | **内容**                                                   |
| -------------- | ---------------------------------------------------------- |
| **物理接口**   | USB 2.0 (Type-C) via STM32 USB CDC                         |
| **波特率**     | 自适应                                                     |
| **字节序**     | 小端(低位放低地址)                                         |
| **坐标系标准** | X轴: 车头朝前 Y轴: 车身左侧 Z轴: 垂直向上 旋转: 逆时针为正 |
| **单位标准**   | 距离: 米 (m), 角度: 弧度 (rad), 时间: 毫秒 (ms), 速度: m/s |



#### 协议帧结构

| **字节**  | **名称** | **值/定义**   | **说明**                                       |
| --------- | -------- | ------------- | ---------------------------------------------- |
| 0         | Head1    | `0x55`        | 帧头标识1                                      |
| 1         | Head2    | `0xAA`        | 帧头标识2                                      |
| 2         | FuncID   | `0x00`~`0xFF` | 功能字 (见下表)                                |
| 3         | Len      | `N`           | 载荷长度 (Bytes)                               |
| 4 ~ 4+N-1 | Payload  | `Data...`     | 具体数据                                       |
| 4+N       | CheckSum | `Sum`         | 校验和 (Byte0 到 Byte 4+N-1 的累加和，取低8位) |



#### 功能字表

| **ID**   | **发送方** | **功能名称**       | **用途**                                                     |
| -------- | ---------- | ------------------ | ------------------------------------------------------------ |
| **0x01** | 上位机     | **时间同步校准**   | 对齐时间戳 (上位机发时间戳给STM32)                           |
| **0x02** | STM32      | **错误报告**       | 硬件故障、急停状态反馈                                       |
|          |            |                    |                                                              |
| **0x10** | 上位机     | **底盘运动指令**   | 基础遥控                                                     |
| **0x11** | 上位机     | **步态/姿态切换**  | 切换模式：站立 / 趴下 / Trot / 跳跃 等等                     |
| **0x12** | 上位机     | **机械臂关节控制** | 发送 3 个关节的目标角度 (Rad)                                |
| **0x13** | 上位机     | **机械臂吸盘控制** | 开启/关闭吸盘 (0/1)                                          |
|          |            |                    |                                                              |
| **0x20** | 上位机     | **局部路径点**     | 路径规划下发的下一个目标点（暂时先不实现，先留着接口也许之后用） |
|          |            |                    |                                                              |
| **0x21** | 上位机     | **地形/避障信息**  | 检测到的台阶高度或障碍距离(暂时先不实现，小概率用)           |
|          |            |                    |                                                              |
|          |            |                    |                                                              |
|          |            |                    |                                                              |
| **0x30** | STM32      | **全身关节状态**   | 腿部电机 + 3机械臂电机角度 (这个可以先只实现机械臂的电机角度) |
|          |            |                    |                                                              |



#### 详细载荷定义

>都用一字节对齐

##### **[0x01] 时间同步校准 (上位机 -> STM32)**

- 数据长度： 8 字节

| **偏移** | **类型** | **名称**   | **说明**                |
| -------- | -------- | ---------- | ----------------------- |
| 0        | double   | **s_time** | 上位机当前的时间戳 (秒) |

(这个比较特殊，linux的计时是按秒来的)

##### **[0x02] 状态报告 (STM32 -> 上位机)**

- 数据长度： 2 字节

| **偏移** | **类型** | **名称**       | **说明**                                   |
| -------- | -------- | -------------- | ------------------------------------------ |
| 0        | uint8    | **dog_state**  | 0:初始化, 1:空闲, 2:任务执行, 3:急停锁定   |
| 1        | uint8    | **error_code** | 0:正常, 1:电池低压, 2:电机过热, 3:通讯丢失 |

(这个就是状态码，我这里乱写的，具体状态码定义你们来决定)



##### **[0x10] 底盘移动指令 (上位机 -> STM32)**

（超过 100ms 没包发来就刹停）

- **数据长度：** 12字节

| **偏移** | **类型** | **名称** | **说明**          |
| -------- | -------- | -------- | ----------------- |
| 0        | float    | **vx**   | X轴线速度 (m/s)   |
| 4        | float    | **vy**   | Y轴线速度 (m/s)   |
| 8        | float    | **wz**   | Z轴角速度 (rad/s) |



##### **[0x11] 步态模式切换 (上位机 -> STM32)**

- **数据长度：** 1 字节

| **偏移** | **类型** | **名称**    | **说明**                               |
| -------- | -------- | ----------- | -------------------------------------- |
| 0        | uint8    | **gait_id** | 0:被动, 1:站立, 2:Trot, 3:Walk, 4:Jump |

(这个是调试用的)



##### **[0x12] 机械臂关节控制 (上位机 -> STM32)**

- **用途：** 下发机械臂 3 个关节的目标角度（逆运动学解算结果）。
- **数据长度：** 12 字节

| **偏移** | **类型** | **名称**    | **说明**            |
| -------- | -------- | ----------- | ------------------- |
| 0        | float    | **joint_1** | 基座旋转关节 (rad)  |
| 4        | float    | **joint_2** | 大臂俯仰关节 (rad)  |
| 8        | float    | **joint_3** | 小臂/末端关节 (rad) |



##### **[0x13] 机械臂吸盘控制 (上位机 -> STM32)**

- **数据长度：** 1字节

| **偏移** | **类型** | **名称** | **说明**   |
| -------- | -------- | -------- | ---------- |
| 0        | uint8    | **mode** | 0:关, 1:开 |


##### **[0x20] 局部路径点 (上位机 -> STM32)**

- **数据长度：** 12 字节

| **偏移** | **类型** | **名称**       | **说明**                     |
| -------- | -------- | -------------- | ---------------------------- |
| 0        | float    | **target_x**   | 目标在当前狗坐标系下的 X (m) |
| 4        | float    | **target_y**   | 目标在当前狗坐标系下的 Y (m) |
| 8        | float    | **target_yaw** | 期望到达时的朝向 (rad)       |


（先不用实现，写来备用的）



##### **[0x21] 减速带信息 (上位机 -> STM32)**

- **数据长度：** 4字节

| **偏移** | **类型** | **名称** | **说明**      |
| -------- | -------- | -------- | ------------- |
| 0        | float    | **dist** | 减速带距离(m) |

(一样的先不实现)



##### [0x30] 关节与运动反馈 (STM32 -> 上位机)

- **数据长度：** 68字节

| **偏移** | **类型**  | **名称**       | **说明**                |
| -------- | --------- | -------------- | ----------------------- |
| 0        | float[12] | **leg_joints** | 12个腿部电机角度 (rad)  |
| 48       | float[3]  | **arm_joints** | 3个机械臂电机角度 (rad) |
| 60       | float     | **est_vx**     | STM32 维护的当前X速度   |
| 64       | float     | **est_vy**     | STM32维护的当前Y速度    |
| 68       | float     | **est_wz**     | STM32维护的当前角速度   |

(先不要轮子电机)
